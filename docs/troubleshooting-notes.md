# Troubleshooting Notes

## General Help Desk Troubleshooting Flow

1. Confirm the issue.
2. Ask when the issue started.
3. Identify the affected device, user, or application.
4. Check whether the issue affects one user or multiple users.
5. Collect error messages or screenshots.
6. Perform basic troubleshooting.
7. Document each step.
8. Resolve or escalate with clear notes.

## Useful Questions to Ask Users

- What were you trying to do?
- What happened instead?
- When did the issue start?
- Did anything change recently?
- Is anyone else affected?
- Are you receiving an error message?
- Have you restarted the device?
- Are you connected to the network or VPN?

## Common First Steps

- Restart the application.
- Restart the computer.
- Confirm internet connectivity.
- Check login credentials.
- Check disk space.
- Check recent updates.
- Test with another browser or device.
- Review error messages.
- Collect system information.

## Good Ticket Notes Include

- User impact
- Troubleshooting steps
- Commands or scripts used
- Results found
- Resolution
- Escalation notes if needed
- User confirmation

## Example Ticket Note

User reported slow computer performance. Collected system information, checked disk space, reviewed running services, and confirmed low free space on the system drive. Removed unnecessary temporary files according to support process and advised user to archive large files to approved storage. Performance improved after restart.
